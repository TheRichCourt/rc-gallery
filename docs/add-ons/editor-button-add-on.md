# Editor button add-on

The editor button add-on adds a button to the Joomla article editor that makes it easy to insert gallery tags without typing them manually.

## How it works

Once installed and enabled, a button appears below the article editor. Clicking it opens a popup where you can:

1. Choose the image folder for your gallery
2. Optionally override plugin settings (row height, margins, etc.)
3. Click "Insert" to add the `{gallery}` tag into your article

This add-on was originally available as a separate download from therichcourt.com. Its compatibility with Joomla 5/6 has not been verified.

> [!NOTE]
> You can always insert gallery tags manually without this add-on. See [Include in an article](../include-in-an-article.md) for details.
