# Layouts add-on

The layouts add-on provides alternative gallery layouts beyond the default justified layout.

## How it works

Once installed, additional layout options become available in the plugin settings. You can choose a layout globally or override it per gallery using inline parameters.

This add-on was originally available as a separate download from therichcourt.com. Its compatibility with Joomla 5/6 has not been verified.

> [!NOTE]
> The default justified layout works without this add-on. Only install it if you need alternative layout styles.
